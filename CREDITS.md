## How it is made

Designed, directed and tested by Allemano. Much of the code is written with AI assistance (Claude, by Anthropic) under that direction. Releases are tested in the game before they are published, and the changelog says what changed.

## Third-party code

Arbiter Soft Reserve contains no third-party code or libraries. It uses the World of Warcraft API and the public interface of Arbiter Loot Council, which it needs. It reads lists exported from softres.it, but contains nothing from that site.
